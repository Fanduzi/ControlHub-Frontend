问题

Schema Metadata Identity 从三处拉取泄漏；QuerySchemaStore 是 shallow 的——它的 interface 就是 acquire-slot / set-loading / set-detail。

做法

一个按（查询目标, 数据库）键控的 deep catalog。列表、详情、补全 namespace 都坐在这个 interface 后面。Slot 协议变成内部 seam。

收益

  • locality：Identity 只活一处
  • leverage：3 个调用方，1 个 interface
  • 两个 adapter 证明这条 seam
  • 删掉 slot 协议
  • SQL 补全消费 catalog

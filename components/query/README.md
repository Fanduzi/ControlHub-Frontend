| sql-code-editor-client.tsx | Client-side CodeMirror editor with engine-specific SQL extensions and completions. Redis uses native command text in the same editor. MySQL and PostgreSQL completions classify the caret through `sqlCompletionSite` in `lib/sql-completion-scope.ts` (statement-local bindings, no regex alias fallback): a qualified-column slot replaces the whole field token — partial quoted input gets the quoted apply as `label` and the raw name as `displayLabel`, and only a mid-token edit disables CodeMirror filtering (which would match labels against the entire replaced token) in exchange for the source's own prefix match on the text before the caret, while an end-of-token site keeps default narrowing — generic sites offer catalog/keyword vocabulary plus relation-position CTE names filtered against colliding canonical table labels; other engines keep the existing namespace path and ClickHouse keeps its dedicated source. Declares `.cm-content` keyboard entry explicitly (`tabindex` 0, or -1 while disabled). Marks the statement Run will execute when the draft holds at least two statements and nothing is selected, and reports the resolved run scope for the Run control's description. |

Approved Redis keys appear in the existing Objects pane. The command editor, Run, result grid and history are shared across engines.

The shared `ResultTable` in `query-editor-shell.tsx` backs both the execute result grid and `RelatedRecordsPanel`; each mounts with `key={executionId}` so every delivered result remounts it. Export offers CSV and JSON (`query-results.csv` / `query-results.json`) for the current delivered page only, gated by the target's server-computed export capability and the shared whole-page eligibility contract in `lib/query-result-export.ts` — a protected, truncated, or malformed cell disables both formats without a download event, and the related-records panel offers neither. Shift-click or Shift+arrow extends one rectangular selection across `aria-selected` cells, Escape clears it, and Ctrl/Cmd+C or the toolbar serializes it as TSV through `lib/query-result-range.ts` — copy is refused when the rectangle contains a non-copyable column, a truncated cell, or a missing/malformed flag, while restricted cells outside the rectangle never block it; scalar cells, headers, the cell viewer, and FK navigation keep their single-cell behavior. Each column header owns a pointer-drag resize handle plus Shift+Left/Right keyboard resizing (clamped 104–640px); widths are transient presentation state that resets on every execution-keyed remount and never enters a governed payload.

Approved Redis keys appear in the existing Objects pane. The command editor, Run, result grid and history are shared across engines.

The shared `ResultTable` in `query-editor-shell.tsx` backs both the execute result grid and `RelatedRecordsPanel`; each mounts with `key={executionId}` so every delivered result remounts it. Shift-click or Shift+arrow extends one rectangular selection across `aria-selected` cells, Escape clears it, and Ctrl/Cmd+C or the toolbar serializes it as TSV through `lib/query-result-range.ts` — copy is refused when the rectangle contains a non-copyable column, a truncated cell, or a missing/malformed flag, while restricted cells outside the rectangle never block it; scalar cells, headers, the cell viewer, and FK navigation keep their single-cell behavior. Each column header owns a pointer-drag resize handle plus Shift+Left/Right keyboard resizing (clamped 104–640px); widths are transient presentation state that resets on every execution-keyed remount and never enters a governed payload.
